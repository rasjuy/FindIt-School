FINDIT SCHOOL — GITHUB PAGES

CARA UPLOAD KE GITHUB
1. Buat repository baru bernama findit-school.
2. Atur repository menjadi Public.
3. Pilih Add file > Upload files.
4. Ekstrak ZIP ini terlebih dahulu, lalu upload index.html dan README.md
   langsung ke halaman utama repository (root).
5. Klik Commit changes.
6. Buka Settings > Pages.
7. Pada Build and deployment, pilih:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
8. Klik Save dan tunggu proses publikasi selesai.
9. Alamat website biasanya:
   https://USERNAME.github.io/findit-school/

CATATAN PENTING
- Website ini adalah prototipe front-end.
- Laporan disimpan di localStorage browser/perangkat masing-masing.
- Data tidak otomatis dibagikan atau disinkronkan antar siswa/perangkat.
- Agar semua siswa melihat data yang sama, perlu database online dan aturan
  keamanan, misalnya Firebase, serta persetujuan/pengelolaan dari pihak sekolah.
- Jangan memasukkan alamat rumah, nomor telepon pribadi, atau informasi sensitif.
